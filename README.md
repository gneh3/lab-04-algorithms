z# Алгоритмический мини-пакет

Лабораторная работа №4 по Python.

Числа Фибоначчи вычисляются двумя способами: циклом и рекурсией.
Нумерация начинается с нуля: F(0) = 0, F(1) = 1.
Обе функции принимают неотрицательное целое число.
Неверный тип вызывает TypeError, отрицательное число — ValueError.
Значения bool не принимаются.

Рекурсивная версия повторно вычисляет одни и те же значения, поэтому
работает медленно на больших n. Глубина рекурсии ограничена Python.
Текущее ограничение можно узнать через sys.getrecursionlimit().
При его превышении возникает RecursionError.

Сортировки insertion_sort и merge_sort возвращают новый список,
исходный не меняют. Поддерживают пустой список, дубликаты и отрицательные числа.
Принимают только список целых чисел без bool, иначе вызывают TypeError.

Очередь Queue работает по правилу FIFO: первым добавлен — первым извлечён.
Она использует собственный односвязный список LinkedList.
Добавление идёт в конец через enqueue, извлечение из начала — через dequeue.
peek возвращает первый элемент без удаления.
Есть len и bool. Извлечение и просмотр пустой очереди вызывают IndexError.

Генераторы создают случайные, отсортированные, обратные, почти отсортированные
списки и списки с большим количеством дубликатов.
Одинаковый seed при одинаковых аргументах даёт одинаковые данные.
Размер должен быть целым неотрицательным числом.

```text

```

Проверяются крайние случаи, ошибки ввода, сохранность исходного списка,
FIFO, связи узлов и воспроизводимость генераторов.

## Benchmark

```text
python src/benchmark.py
```

Сравниваются две сортировки на пяти типах входа.
Размеры — 100, 1 000 и 10 000, по пять повторов.
Настройки находятся в consts.py.

Время измеряется через perf_counter. Генерация данных, подготовка отдельной
копии для каждого запуска и проверка ответа не входят в измерение.
Обе сортировки получают одинаковые значения.
Внутреннее копирование самой сортировки входит в её время.

Все 150 измерений записываются в benchmark_results.csv в текущей рабочей папке.
Существующий файл перезаписывается. В CSV время указано в секундах,
в консоли выводится среднее время в миллисекундах.

## Сложность

| Алгоритм | Время | Дополнительная память |
|---|---|---|
| Фибоначчи циклом | O(n) | O(1) |
| Фибоначчи рекурсией | O(2ⁿ), верхняя оценка | O(n) |
| Insertion sort | O(n²), на отсортированном входе O(n) | O(n), включая копию |
| Merge sort | O(n log n) | O(n) |
| Добавление, извлечение, просмотр очереди | O(1) | O(1) на операцию |
| len и bool очереди | O(1) | O(1) |

Для Фибоначчи указано число арифметических операций и хранимых чисел:
при больших n стоимость операций и память для длинных целых тоже растут.
Сама очередь занимает O(n) памяти.

Случайный набор и набор с дубликатами создаются за O(n).
Отсортированный, обратный и почти отсортированный наборы — за O(n log n),
так как при подготовке используется sorted. Все наборы занимают O(n) памяти.

В измерениях insertion sort значительно быстрее на отсортированном
и почти отсортированном входе. На случайном и обратном входе время растёт
примерно квадратично. Merge sort на больших случайных списках быстрее,
а рост времени ближе к O(n log n). Отдельные измерения могут отличаться
из-за нагрузки системы, поэтому сравниваем средние пяти повторов
для одинакового типа входа.
